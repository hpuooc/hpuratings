# hpuratings

Competitor comparison landing pages for hpuratings.com.

Each school has its own folder containing a single self-contained `index.html`.
Every page embeds its own CSS and images, so there are no build steps, no
dependencies and no external requests.

| Path | Page |
| --- | --- |
| `/tampa/` | High Point University vs. the University of Tampa |
| `/marist/` | High Point University vs. Marist University |
| `/loyola-maryland/` | High Point University vs. Loyola University Maryland |
| `/quinnipiac/` | High Point University vs. Quinnipiac University |
| `/ithaca/` | High Point University vs. Ithaca College |
| `/monmouth/` | High Point University vs. Monmouth University |
| `/chapman/` | High Point University vs. Chapman University |
| `/pepperdine/` | High Point University vs. Pepperdine University |

Every competitor claim on every page is sourced to that school's own published
pages. The citations live in `research/07-DATA-CATALOG.md` in the working
project, not in this repo.

Ads for these pages do not run in Florida.
